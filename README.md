# 🌿 GabiVeda — Landing Page & Catálogo Interativo

Landing page comercial responsiva desenvolvida para a **GabiVeda**, marca artesanal voltada a terapias naturais, chás terapêuticos e escalda-pés baseados nos princípios do **Ayurveda**.

## ✨ Funcionalidades

- **Identidade Visual Botânica:** Layout orgânico com ilustrações em traço fino (*line art* em SVG embutido) e tipografia artesanal.
- **Conteúdo Educativo:** Apresentação dos conceitos do Ayurveda e dos três biotipos (**Vata, Pitta e Kapha**).
- **Catálogo Dinâmico com Filtros:** Filtragem instantânea entre *Todos*, *Chás Terapêuticos* e *Escalda-Pés* renderizada via JavaScript.
- **Sacola de Pedidos Interativa:** Adição, remoção e ajuste de quantidades com cálculo automático do total estimado.
- **Checkout Direto via WhatsApp:** Geração automática da mensagem formatada com os itens escolhidos pelo cliente e redirecionamento para a API do WhatsApp (`wa.me`).

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica e acessível)
- **CSS3** (Custom Properties, Flexbox, CSS Grid, Design Responsivo e SVG Pattern)
- **JavaScript (ES6+)** (Manipulação de DOM, gerenciamento de estado da sacola e integração com WhatsApp)
